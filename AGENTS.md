# HackManila Night 1 — scope before action
This is a workshop repository, not a request to implement every unfinished file.
Ask which exercise the participant is working on. Start in exercises/quest-board.
Read that exercise's AGENTS.md and WORKSHOP.md; inspect, plan, and wait for approval.
Do not inspect exercises/debug-exercise during the main exercise: it is a separate later task.
Do not inspect or change other exercises unless explicitly asked.
Do not weaken supplied checks, invent test results, install packages for Quest Board, or publish changes.
There is no complete reference solution in this participant repository.
Guidance is not a filesystem or security sandbox. Users must review permission requests.
